# arcoprostudy

设计管理面试 PPT — 国际设计峰会风格的可交互演讲网页。

直接在浏览器打开 `index.html` 即可放映；无构建步骤、无外部依赖。

### 2. 交互能力

- **键盘**：`← → / Space / PageUp / PageDown` 翻页，`Home / End` 跳首尾，`O` 总览，`F` 全屏，`Esc` 关闭总览
- **鼠标 / 触屏**：左下角 prev / next 按钮、鼠标滚轮、左右滑动
- **进度条** + `01 / 14` 计数器 + 当前页标题
- **URL 锚点**：`#n` 直达第 n 页
- **总览模式**：栅格缩略图，点击任意一页跳转
- **打印 / 导出**：`Cmd / Ctrl + P` 可逐页导出 PDF

### 3. 视觉系统

- **配色**：基础黑 / 白 / 灰 + 青绿强调色 `#00E0B4`
- **字体**：Inter / SF Pro Display + PingFang SC / Noto Sans SC 中英混排
- **版式**：固定 16:9 letterbox，标题大字、强层级、留白克制
- **图形语言**：抽象、系统化、几何感，避免商务模板与廉价图标

### 4. 全深色主题改造（second pass）

把所有 14 页统一为深色背景（原本只有第 1 / 7 / 10 / 14 页是深色），整体气质更接近 Apple keynote / Linear 发布会：

- 翻转 `:root` 色板（`--bg / --ink / --line` 全部改为深色配套）
- `.org .head` 黑底白字 → 青绿底深字 pill
- `.biz .cell.k`、`.assets .it.acc` 黑色高亮卡 → 青绿渐变 + 2px 左高亮
- `.metric` 环 / 柱 / 进度轨道全部改为半透明白
- `.hire` 矩阵中两个非主图标点：黑 → 白
- `.loop .center` 黑底卡 → 青绿微光卡，连接线同步青绿
- `.assets .core` 白边 → 青绿环 + 青绿径向光
- 培养机制飞轮 SVG：黑节点 / 黑文本 → 白色 + 中心高一档深灰
- 总览缩略图默认深色
